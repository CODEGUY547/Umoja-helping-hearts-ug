# Umoja Helping Hearts Uganda Website

This folder contains the redesigned Umoja Helping Hearts Uganda website.

## Preview

Open `dist/index.html` directly, or serve the `dist` folder with a local web server.

## Main files

- `dist/index.html` — website structure and content
- `dist/styles.css` — responsive design and visual styling
- `dist/script.js` — splash screen, navigation and subtle reveal effects
- `dist/assets/` — Umoja logo and project photography
